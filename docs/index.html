HavenOS

A lightweight Linux smart-home OS for old Android tablets, built to run on the device itself.

First device

ASUS Nexus 7 (2012). Wi-Fi boards are grouper. Cellular boards are tilapia.

Principles

  • Lightweight enough for old tablet hardware
  • Linux, not Android
  • Local-first
  • No Home Assistant required

Firmware is not downloadable yet. There is no image to flash, and this page is not an installer.
