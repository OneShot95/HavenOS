# HavenOS

HavenOS is a lightweight, independent Linux smart-home OS for old Android tablets.

The first device is the ASUS Nexus 7 (2012): **grouper** (Wi-Fi) and **tilapia** (cellular).

## What it is not

HavenOS is not an Android launcher, not an Android app, and not a browser simulation of a control panel.

## Status

The shell in `shell/` is a desktop prototype. It is not a flashable image, and nothing here is firmware you can download.

Flashing requires the exact model to be confirmed, and an explicit go-ahead. Do not flash a device from this repository.
